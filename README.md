🚀 Features

✔️ No Machine Learning Used — Pure rule-based fraud detection

✔️ Detects suspicious SMS patterns

✔️ Keyword-based filtering (e.g., "win", "lottery", "OTP", "urgent")

✔️ Detects phishing links / fake websites

✔️ Simple login & signup pages

✔️ Node.js backend server

✔️ Fast, lightweight, and beginner-friendly

🧠 How It Detects Fraud (Logic Used)

The system uses rule-based logic such as:

✔️ Keyword matching (e.g., “Congratulations”, “FREE”, “Claim now”)

✔️ Blacklisted phrases

✔️ Detection of shortened URLs (bit.ly, tinyurl, etc.)

✔️ Suspicious patterns in SMS

✔️ Regex-based detection for risky numbers/links

▶️ How to Run the Project
1. Install Dependencies
npm install

2. Start the Server
node server.js

3. Open in Browser
http://localhost:3000
